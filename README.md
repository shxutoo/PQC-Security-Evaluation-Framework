# PQC Security Evaluation Framework

A framework for evaluating classical and post-quantum cryptographic algorithms through performance benchmarking and security analysis.

## Overview

This project focuses on analyzing the impact of quantum computing on modern cryptographic systems and evaluating post-quantum cryptographic alternatives.

## Objectives

- Analyze vulnerabilities of classical cryptographic algorithms against quantum attacks.
- Evaluate post-quantum cryptographic algorithms.
- Compare performance characteristics through benchmarking.
- Visualize experimental results.

## Algorithms Under Evaluation

### Classical Algorithms
- RSA
- Elliptic Curve Cryptography (ECC)

### Post-Quantum Algorithms
- ML-KEM (Kyber)
- ML-DSA (Dilithium)
- SLH-DSA (SPHINCS+)
